## The wall

You saved it. You know you saved it. Now you're scrolling a folder called "Stuff" looking for a link you can picture but can't name.

Xtreme Bookmarks turns the browser's flat list into something you can search, tag, and clean. The sidebar opens over the page you're reading, so you don't lose the tab you were on to find the tab you wanted.

## What changes

**Search that respects scope.** Global or folder-only, with tags and filters instead of a substring match over titles.

**States on the bookmark itself.** Read later, Reading, Done, Important. Favorites get promoted. Small labels that replace the sticky-note system you don't actually maintain.

**A sidebar workspace.** Resizable, opens over the current page, closes without touching your tabs.

**Cleanup you approve step by step.** Duplicate groups get reviewed, not auto-deleted, so you pick the copy that survives. Same-name folders in the same location merge, with the safe path first.

**Broken links surfaced before removal.** Scan the library, review what's unreachable, then decide.

**Visual structure.** Folder colors across a wide palette, so a large tree reads at a glance.

**Moving between browsers.** Export and import bookmarks as HTML, and carry extension settings across setups.

## Who it's for

Researchers with a hoard of references. Anyone who migrated from browser to browser and lost the structure twice. People who save first and organize never.
